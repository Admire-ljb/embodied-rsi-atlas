环境工具层

仿真环境服务

Skill 通过 MCP 环境接口调用仿真工具。替换底层仿真环境时，适配器按同一约定处理工具名称、参数、返回值和时间单位。

首个 MCP 适配器

时钟工具接入示例

Skill 定义何时调用工具、如何核对回执，以及如何解释返回结果。标准客户端通过 tools/list 发现工具及参数，通过 tools/call 调用。基线与新测结果均带运行号、事件标识和逻辑秒数。

读取基线

read_clock_reference(run_id)

从两次已发布的 AFSIM 实测中选择一条，返回该次实验的时钟标记和来源。

发起一次新测量

measure_clock_markers()

在本地启动一次固定的无实体时钟实验，生成新的运行号并返回实际输出。每次调用都使用同一份双标记输入。

查看调用示例与 kagent 绑定方式
{"jsonrpc":"2.0","id":3,"method":"tools/call",
 "params":{"name":"measure_clock_markers","arguments":{}}}

测量 Skill 先读取基线，再发起新测量，逐项对照标记和时间。kagent 的声明式 Agent 通过 mcpServer.toolNames 绑定这两个名称。集群接入需提供可达的 Streamable HTTP 服务，运行记录通过实例编号和调用标识关联工具回执。

官方 MCP 客户端已在 stdio 和 Streamable HTTP 上分别完成工具发现、读取基线与新测量。AFSIM 2.9.0 的两次新测均得到 1 秒和 3 秒的标记。GitHub Pages 提供代码、说明与实测记录。集群 Agent 调用与候选版本评价仍待验证。
