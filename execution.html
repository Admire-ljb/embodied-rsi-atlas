具身智能 RSI

执行面原型

先用离线记录验证一项任务怎样分步执行、成员怎样交接结果，以及一次失败能否追溯到具体步骤。环境服务可随任务更换。

一次任务怎样运行

  1. 任务编排

    AeroWeaver 根据任务组织角色，确定可用 Skill 与步骤依赖。

  2. Agent 执行

    本地 Agent 按上下文选择 Skill，通过 MCP 工具读取环境记录。

  3. 成员交接

    通过 A2A 传递中间结果，保留消息标识和原始记录引用。

  4. 运行归档

    按运行号关联步骤、回执与错误，供协作度量和版本比较使用。

这是端到端联调的目标。可先用 AeroWeaver 原有的 Coverage 任务核对编排，再逐项替换 Skill 和环境工具。kagent 实例运行、跨实例 A2A 交接和完整链路仍待联调。六个可独立测试的模块

运行离线样例

任务是汇总一批仪表读数，找出缺失项。浏览器按所选输入执行读取、交接与汇总，最后与样例中的预期结果核对。三个用例均在本页本地运行。

    两条基线分别完成一次新测量。另一次撤去仿真可执行文件配置，执行器保留已读取的基线，并返回 incomplete。三次调用轨迹均可下载。
