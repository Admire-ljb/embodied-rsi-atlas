# 具身智能研究图谱

面向学生的研究选题与实验设计。五层框架对应概念定义、研究机理、评测与治理、平台支撑和领域验证。首轮以桌面分拣、室内盘点、台架回放为例，设置三组九个拟议课题，另设一名总体协调人。页面中的假设、时间安排和示意数据用于开题讨论。

[浏览网页](https://admire-ljb.github.io/embodied-rsi-atlas/)

## 使用

打开 `index.html` 即可离线浏览。打开一个课题可查看研究问题、对照实验、评价指标、协作依赖和首周任务，支持下载 Markdown 开题卡。下载后的卡片可填写并交给导师讨论。

## 接入研究框架

每项交付请注明输入样本版本、所属平台模块、可复现实验、对照组和失效条件。开发样本和隐藏留出样本分别管理。学生提交去标识化的摘要；涉及未获公开授权的数据或个人信息时，使用课题组内部渠道。

- 表征与回放组交付事件字典、回放包和已知原因的异常样本。
- 度量与验证组独立维护指标、基线和留出评测。
- 经验与适配组交付候选版本，将评测结果和负例交回独立评测组。

## 维护

直接修改 `index.html` 中相应的课题条目即可同步更新详情与下载卡片内容。筛选、下载和台架示意由 `atlas.js` 提供，样式位于 `atlas.css`。`bench-example.csv` 的三行是与首页示意对应的虚构记录。
