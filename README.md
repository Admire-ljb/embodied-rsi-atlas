# 集群博弈研究图谱

课题一面向高速固定翼无人机集群的群体对抗博弈。网页按立项书的三个研究方向组织，面向学生提供三项主课题和六项协作选题。

| 章节 | 研究方向 | 首轮交付 |
| --- | --- | --- |
| 3.2.1 | 个体—群组—整体的跨尺度状态与行为模型 | 观测字典、状态标注与不确定性报告。 |
| 3.2.2 | 群智共识与协作增益的综合度量 | 对照协议、协作指标和共同误判样例。 |
| 3.2.3 | 分层群智决策、角色组织与策略演化 | 分组收益表、基线比较和适用条件。 |

## 浏览和使用

打开 `index.html` 可以离线浏览。按方向、研究起点或关键词筛选课题，展开后可下载 Markdown 开题卡。分工按岗位展示，建议由一名协调人和三个三人研究组协作。

## 共同示例

首页比较三种信息条件下的一致率、共同误判率和平均团队收益。每组含 100 局合成数据。一致率与共同误判率均以全部对局为分母。平均收益的示例范围为 0 至 1。CSV 位于 `bench-example.csv`，仅用于演示指标读法。

## 维护

题目、实验说明与首周任务集中在 `index.html`。开题卡从对应条目生成。编辑示例数据时需同步修改页面图表中的数值和说明。GitHub Pages 使用 main 分支的根目录发布。
