# 高速固定翼无人机集群群体对抗博弈研究框架

课题一以跨尺度状态表征、群智共识与协作增益、策略适应与泛化为长期研究方向。首页呈现研究体系、实验架构、方向依赖和可下载的成果库。学生在独立的研究点地图中认领可独立检验的问题。公开分工只列岗位。

## 使用

- index.html 为框架首页。
- topics.html 提供学生研究点、开题卡与交接说明。原首页的学生选题锚点仍可使用。
- research-assets.json 登记成果编号、版本、归属模块、依赖和适用范围。
- research-record.txt 是可复制的成果登记模板。
- consensus-example.csv 与 consensus-note.txt 提供八条合成样本和复算记录。
- 学生页的 bench-example.csv 单独用于三个指标的对比图。

## 交接一项研究

选定科学问题和接入模块，引用样本、基线与评价协议版本。按登记模板填写对照、原始结果和反例，将文件提交至仓库，在 research-assets.json 中登记新版本与准确的上游编号。首页自动读取索引、显示下载链接与上游版本。后续工作注明上游版本，保留受影响的旧记录及其适用条件。

网站使用静态 HTML，可在本地直接打开。GitHub Pages 从 main 分支根目录发布。
