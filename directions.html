研究方向规划图

以高速固定翼集群仿真为实例，三个方向共用具身智能 RSI 架构的运行记录，研究个体状态、群体协作与跨任务的策略改进。

三个研究方向

个体—群组—整体的跨尺度状态与行为模型

  • 描述单个智能体的观测、记忆和行为，保留信息来源与时间。
  • 研究如何由个体记录表示群组关系和整体任务进度，并标明观测缺失带来的不确定性。

群智共识与协作增益的综合度量

  • 分析成员判断的依据，区分独立观测和同一消息的重复转发。
  • 在相同任务与信息预算下，比较独立判断与协作判断的准确性、共同误判率及通信开销。

分层群智决策、角色组织与策略演化

  • 研究任务层、群组层与个体层的分工，以及任务执行中的角色交接与反馈。
  • 研究如何从运行经验中调整技能或选择规则，并在未见任务上检验改动的收益与退化。

第一阶段 · 基于离线数据搭建完整的 Agent 框架

六个模块按共同的输入、输出、错误和版本约定并行开发，各自用测试替身验收。首轮可沿用 AeroWeaver 的 Coverage 任务联调，以同一任务逐项复测替换后的 Skill 和 MCP 工具。AFSIM 离线记录另用于验证指定时刻的观测查询。

共用的验收样例　同一批仪表读数中包含有效值、空值和零值。各模块共用任务、记录标识与预期结果，分别测试正常执行、数据缺失及消息重送。下载样例与预期结果（JSON）

独立模块输入与输出怎样单独测试独立验收条件
离线环境与 MCP 工具接收数据集标识和查询条件，返回记录、来源或错误码。用本地离线样例启动工具服务，以 MCP 测试客户端发现工具、发起调用并检查回执。指定样本返回 r1 至 r3。请求不存在的数据集，返回可识别的错误。
单 Agent 运行时接收任务上下文、模型与 Skill 配置，执行后返回状态、结果及运行事件。在 kagent 测试环境运行单个 Agent。用固定响应的模型适配器、内存存储和测试 Skill 驱动 Harness。连续运行两项任务，上下文相互隔离。测试 Skill 出错时能定位失败步骤。
Skill 封装与注册按名称和版本发现与调用 Skill，约定输入、输出、错误和来源引用。用命令行测试入口直接调用真实 Skill。以固定回执代替外部工具，分别检查检索和摘要逻辑。三条记录中只将 r2 列为缺失，零读数有效。缺少必填参数时返回约定错误。
任务规划与应用编排AeroWeaver 接收任务和能力清单，生成含 Skill、角色与依赖的计划，交付可调度步骤。用静态能力清单、模拟执行器单测编排器。分别输入完整指令、变更指令和某一步执行失败的回执。计划只引用已登记能力，依赖无环，上游结果可供下游使用。失败后给出可观察的状态。
A2A 通信与交接传递任务、中间结果与状态，保留运行号、步骤号、消息标识及证据引用。运行真实通信适配器，使用本地 A2A 测试对端收发消息。按脚本模拟正常应答、重复投递和超时。同一消息投递两次，得到两条投递记录和一次业务接收。超时可在调用端识别。
运行记录与版本管理接收版本信息和结构化事件，按运行号还原计划、工具调用、消息及最终状态。以固定事件序列和临时存储测试归档、检索与回放。按运行号导出验收记录和失败样例。重复导入保持结果一致。指定一次失败运行，能定位最先失败的步骤及应用版本。

最终联调 · 用真实模块完成同一项任务

核对模块交付。 每个模块提供独立启动或调用入口、一条测试命令和验收报告。联调前核对各模块使用的接口版本、运行号与步骤号约定、结果状态和错误含义。

接入真实模块。 各模块单测通过后，用真实服务替换测试对端。AeroWeaver 出计划，kagent 实例执行 Skill，经 MCP 读取离线数据，通过 A2A 交接结果。记录模块按运行号关联全过程。

核对端到端结果。 正常样例应汇总三条记录且只标出 r2 缺失。再运行未知数据集和重复交接用例，分别核对失败位置、去重结果与来源引用。

进入下一阶段的条件　执行框架通过联合验收后，先定义各实例的可见范围与消息投递规则，再开展 A1、A2 对照实验。积累可追溯反例后启动 B1，形成配对评价协议后启动 B2。两者均可复跑后再开展 C1。查看各方向实验与停止条件
