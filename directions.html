三个科学问题

高速固定翼集群仿真中，同一事件到达各成员的时间可能不同，多个成员的判断也可能来自同一条观测。这给分布式具身智能提出了三个可独立检验的问题。

异步局部状态表征

信息延迟或缺失时，哪些历史观测足以支持个体对当前状态的判断？

固定每次判断时已经可见的记录与上下文长度，比较“只保留最新值”和“保留来源、采样时刻与缺失状态”的摘要。按延迟分组统计判断误差与引用未来信息的次数。

A1 局部观测的时间与表征

群体协作增益

通信在什么条件下带来互补信息，又在什么条件下只会放大共同误判？

在同批事件和相同模型调用预算下，对照独立判断、转发同一来源和交换互补观测。后两组匹配消息量。以独立标注计算正确率的配对变化和共同误判率。

A2 共识与协作增益的度量

经验迁移与递归改进

从一次失败中形成的 Skill 改动，在什么条件下能改善未见任务？改进器自身的贡献如何识别？

先冻结模型和预算，在留出批次配对比较原版与候选 Skill，记录收益与退化。候选评价可复算后，再固定初始 Skill 和候选数，比较新旧改进器产出有效候选的比例。

B1 经验复用B2 独立评价C1 递归验证

共同实验基础　P0 可回放基准保存每个 Agent 当时能看到的记录，独立答案单独留给评价者。三条方向据此复用同一批输入和反例。

第一阶段 · 搭建执行面

约 10 人可按五项工作结对并行，每项两人。已有起点是本地时钟 Skill 与三条 MCP 调用轨迹。下面是拟认领的交付，两个独立 Agent 的集成运行是本轮里程碑。

认领模块首个可交接成果联调时如何验收支撑方向
应用编排与运行时一份 AeroWeaver 任务配置与两个 kagent 实例声明，按任务绑定角色、上下文与 Skill。用同一任务启动两个可寻址实例，输出同一运行号、各自的实例标识与 Skill 版本。P0、A2
局部观测与上下文可见记录格式与摘要器。为同一事件保存来源、采样时刻和各实例首次可见时刻。向一个实例延迟投递一条记录。重放截止时刻前的上下文，两实例分别得到预期的可见记录。P0、A1
A2A 消息交接两个实例之间的 A2A 适配及交接样例。消息关联任务、发送者、接收者和观测来源。接收端可定位原始观测。重复投递同一条消息时，仅计作一次证据。A1、A2
Skill 与 MCP 工具将现有时钟 Skill 接入实例，从 Python 执行器调用 MCP 基线读取与新测量工具，保留结构化回执。正常运行返回匹配结果。工具不可用时，实例报告未完成，并保留已取得的基线回执。P0、B1

首轮联合验收

先对齐记录。 五对成员共用一份事件样本，约定运行号、实例标识、观测来源、采样时刻与可见时刻；各模块可先用样例并行开发。

再跑通双实例。 在时钟校验任务中，一个实例经 MCP 读取仿真基线，另一个取得新测量，两者通过 A2A 交换带来源的记录，给出可复算的比较结果。

最后交叉复跑。 交付正常、人工延迟投递、工具不可用三类轨迹。另一对成员应能分别复现匹配结果、迟到记录的可见边界和未完成的原因。人工延迟在样本中单独标记。

进入下一阶段的条件　联合验收通过后，在同一基准上并行开展 A1 和 A2。积累可追溯反例后启动 B1，形成配对评价协议后启动 B2。两者均可复跑后再开展 C1。查看各方向实验与停止条件
